# Kanade theme attribution

This branch adapts [Kanade](https://github.com/sudoriaa/Kanade-Astro/tree/codex/astro-theme) by [sudoriaa](https://github.com/sudoriaa) for Mochiko’s creator website.

Source branch: `codex/astro-theme`  
Source commit: `d5ea45630603305e48682943ee7e8a0569400386`

The design and implementation of the global color system, three-column shell, illustrated welcome header, layered SVG waves, navigation, profile card, sidebars, feed cards, and footer were adapted from that source. The original Vue components were ported to Astro and small TypeScript modules so Mochiko’s existing Astro/Vercel stack stays in place.

Visible UI, accessibility labels, search, fallback states, and documentation are in English. Developer blog examples, article counts, friend links, and the browser-local guestbook were replaced with Mochiko’s own creator content and actual channel links.

Artwork, fonts, icons, creator information, social destinations, and Twitch/YouTube endpoints come from `klokwark/mochiko-web`. The upstream illustration and Chinese font are not included. Attribution links are visible in the footer and on the 404 page.

The referenced upstream snapshot does not contain a LICENSE file. This note records provenance and does not assign or change the upstream author’s rights. The repository’s existing LICENSE is preserved.
